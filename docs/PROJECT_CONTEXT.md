# Project Context

## Goal

Create a frontend-only birthday experience for Zayn's fourth birthday.

The experience should feel playful, emotional, and simple enough for a young child.

## Primary user

A four-year-old child using a touch-screen mobile device with help from a parent.

## Core experience

The child completes puzzles to unlock memories. Finishing the final photo puzzle reveals the birthday celebration and Daddy's personal message.

## Non-goals

- User accounts
- Cloud synchronization
- Admin dashboard
- Server database
- Multiplayer
- Complex analytics
- Landscape layout

## Required UX states

- Default
- Dragging
- Selected for tap-to-place
- Wrong
- Correct
- Completed
- Loading
- Error
- Resume progress
